В рамках контрольной точки необходимо освоить базовые навыки работы с системой контроля версий Git и применить их при разработке многостраничного сайта. Работа включает установку и настройку Git, создание локального репозитория, выполнение коммитов, работу с ветками и слияние изменений. Финальным этапом является публикация проекта на GitHub Pages.
